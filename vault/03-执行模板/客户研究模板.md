# 客户研究模板

| 字段 | 应记录的内容 |
| --- | --- |
| 公司 | 名称、官网域名、国家、行业、主体证据和别名。 |
| 相关人员 | 可核实的岗位、所在公司、公开业务资料来源和观察日期。 |
| 发现依据 | 公司页、公开帖子、群组或目录的依据。区分公开互动、产品场景和明确的采购信号。 |
| 历史覆盖 | 已查渠道、账号范围、时间区间和待补资料。 |
| 业务匹配 | 一条已核实的场景、可提供的方案、需要验证的假设。 |
| 动作建议 | 首触、跟进、研究、观察或停联。提供实际文案和授权状态。 |

在自己的业务项目或客户台账保存工作记录。外部材料仅作为相应事实的证据。
