# 将个人档案整理为业务入口

- 主题：档案
- 适用：创始人、销售与专业人员
- 来源类别：模型已有知识
- 归纳日期：2026-11-19

## 要解决的问题

候选客户看到档案后难以判断谁能提供什么。

## 操作步骤

1. 标题写明角色、买家情境与专长。
2. 简介先说明实际服务对象，再给工作方式及一个已核验事实。
3. 精选展示一到三个资源，每个给出明确用途和一个下一步。
4. 在本人资料与公司说明中交叉核对品牌、主体和网址。

## 交付物

档案草稿和事实清单。

## 如何检验

- 陌生读者能回答服务谁、有什么证据、如何继续。
- 资源能打开，主张都有依据。

## 适用边界

公司页适合正式资料与品牌信息，个人号适合专业经验和讨论。
